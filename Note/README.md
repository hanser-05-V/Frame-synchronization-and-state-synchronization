## 📌 维护规则

- **笔记编号** → 按分类文件夹内递增，三位数
- **配图** → 所有源码实现笔记至少一张交互式 HTML 图，放在 `charts-output/` 下
- **路径引用** → 笔记在子文件夹内时，图表引用使用 `../charts-output/`
- **编写标准** → 严格遵循 [笔记编写规则.md](./笔记编写规则.md)
- **由浅入深** → 概念层 → 核心层 → 单机流程 → 联网流程 → ECS → 协议层
- **分批写入** → 每批笔记完成后汇报帅老大，后续深层次内容等学习对接收后写入
