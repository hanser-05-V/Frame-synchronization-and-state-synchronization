## 笔记定位

**三层定位：**
1. **概念层**（基础介绍）— 可附外部参考链接（知乎等），讲清楚"是什么"
2. **源码实现层**（框架代码）— 按 Ai记录规则——设计意图 + 接口层 + HTML 配图 + 实践注意
3. **实践总结层** — 帅老大学习后吸收总结的内容

## HTML 配图规则

完全参照 Ai记录规则（颜色/箭头/交互/top导览），新增帧同步专用颜色：

```
卡片标题色：
  #2563eb 蓝色 — 引擎/主控类（FrameEngine / BattleManager）
  #059669 绿色 — 数据/缓存类（FrameBuffer / Input）
  #d97706 橙色 — 控制器（IBattleController 子类）
  #7c3aed 紫色 — 网络层（KCP / RemoteBattleNetworkController）
  #475569 灰色 — 工具/辅助类
  #dc2626 红色 — 回滚/异常路径
```

箭头规范、交互功能、布局规则：**同 Ai记录规则**。

## 编写原则

- 一篇笔记一个主题，不写大杂烩
- 避免重复编写相同内容
- 先总结再分点介绍清楚
- 涉及框架代码 → 必须有设计意图 + HTML 配图
- 概念笔记 → 可附外部链接，不强制配图
- ❌ 不写踩坑记录（那是项目笔记的事）
- ✅ 源码实现笔记可以写"实践注意"
