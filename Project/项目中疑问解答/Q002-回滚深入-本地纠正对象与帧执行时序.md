### 追问①：回滚后本地帧输入又执行了一次？

**帅老大原话：**
> "发生回滚后再次进行执行，那不是本地帧输入又执行了一次？"

**💜 参考回答：**

✅ **对，又执行了一次。** 但用的不是"现在的键盘"，而是从 FrameBuffer 取回帧 i 当时存的历史按键记录——保证和第一次执行完全一致。同时快照也被新结果覆盖了。

源码：`GameController.cs:417-459`
```csharp
for (int i = safeFrame + 1; i <= lastExecutedFrame; i++)
{
    _frameEngine.Buffer.GetFrame(i, out frameData);
    inputs[localIdx] = frameData.inputs[localIdx]; // ← 取旧记录，不读键盘
    
    // ... 执行位置更新 ...
    _predictionSystem.TakeSnapshot(i, _blockPosX, _blockPosZ); // ← 覆盖旧快照
}
```

### 追问②：回滚后实际运行帧是现在实际帧还是修复帧？

**帅老大原话：**
> "发生回滚后实际运行帧是变成现在实际的帧还是修复的帧？"

**💜 参考回答：**

**修复后的帧。** 帧号不变，位置变了。回滚只改位置和快照，不改变 `_currentFrame`。

```
回滚前: 帧102位置 = 错误位置（远端预测错）
回滚后: 帧102位置 = 正确位置（远端真值纠正）
_currentFrame = 没变，下一帧从回滚前的帧号继续
```

---

### 追问③：帧记录是保存本地帧输入和预测输入并行嘛？

**帅老大原话：**
> "帧记录是保存的当前本地帧的输入和预测的输入这样并行嘛？实际帧比逻辑帧要快几帧嘛？"

**💜 参考回答：**

**没有"两套"帧，只有一套。** FrameBuffer 存的是 `inputs[2]` 整个数组——`inputs[0]` 是本地真实输入，`inputs[1]` 是远端输入（可能是预测值）。引擎不区分来源，全部当做一个数组存起来。

另外**没有"实际帧比逻辑帧快几帧"之说**——Demo 中只有逻辑帧（30FPS），没有分离的逻辑帧和渲染帧。

---

### 追问④：回滚对所有客户端都进行修复吗？

**帅老大原话：**
> "回滚顿一下的时候，会对所有客户端都进行修复嘛？"

**💜 参考回答：**

❌ **不对。回滚是纯本地的，只有自己的客户端做纠正。**

```
客户端 P1                              客户端 P2
 帧102: 猜P2=空 → 错了                    帧102: 自己的输入本来就是正确的 → 不需要回滚
 帧105: 发现猜错 → DoRollback(102)        （完全不知道 P1 回滚了）
                                          方块位置一直是对的
```

帧同步的核心特点——**两边各自维护自己的世界，各自纠正自己猜错的部分。**

---

### 追问⑤：LateUpdate 处理完所有输入才会下一次 Update 吗？

**帅老大原话：**
> "实际上在 LateUpdate 处理完所有的输入，才会进行下一次生命周期 Update 嘛？"

**💜 参考回答：**

✅ **对。** `DoRollback` 是同步执行的——for 循环跑完才退出。整个重放期间 `FrameEngine.Update()` 不会来插队。

```
Unity 生命周期（同一帧内）：

Update()
  ExecuteOneFrame(103) → 标记 pending
  ExecuteOneFrame(104) → 标记 pending
  ExecuteOneFrame(105) → 标记 pending

LateUpdate()
  DoRollback(102):
    重放103 ✓ → 重放104 ✓ → 重放105 ✓
    跑完才退出 ← 期间 Update 不来插队

（下一帧）
Update()
  ExecuteOneFrame(106) ...  ← 位置已纠正
```

**所以"顿一下"就是 LateUpdate 里同步重放 N 帧的耗时。**

---

### 追问⑥：纠正的到底是什么？

**帅老大的自我总结：**
> "本地自我纠正，纠正的应该是在我本地中其他客户端的实际行为，是不是这样？"

**💜 参考回答：**

✅ **满分。完全正确。**

| 纠正的对象 | 数据来源 | 回滚改什么 |
|:---------|:-------|:---------|
| 我本地自己 | 键盘实时读取 → 永远正确 | 不用改 |
| 远端别人 | 网络延迟传输 → 可能预测错 | ⬅ **回滚只改这个** |

**回滚 = "我刚才猜错了别人在干什么，现在知道真相了，把别人的位置修正一下。"**

---

## 💜 一句话记住

> **回滚 = 本地自我纠正（不等服务器、不通知对方），在 LateUpdate 里 for 循环同步跑完，修正"我猜错的远端行为"，不碰本地自己的输入。**
