## 🔜 下一步：3.4 最小化联机 Demo

> **目标**：在单机 Demo 基础上加网络层，两个窗口的方块互相同步
> **核心原则**：FrameEngine 一行不改！

### 做什么

```
单机 Demo 的基础上加：
  ① C# Console 服务器 — 监听 8888 端口，收到 Input → 广播给所有客户端
  ② 网络层 NetworkClient — 独立线程收发，暴露 GetRemoteInputs()
  ③ GameController.ReadInputs() — 加第四种模式：网络模式
  ④ 两个客户端 — Editor 操控 P1，exe 操控 P2，互相看到对方移动
```

### 新增文件清单

| 优先级 | 文件 | 类型 | 作用 |
|:--:|------|------|------|
| ⭐⭐⭐ | `NetworkServer.cs` | C# Console 程序 | 接收客户端连接 → 收到 Input → 广播 |
| ⭐⭐⭐ | `NetworkClient.cs` | Unity 脚本 | 连服务器 → 独立线程收发 → 暴露 Input 队列 |
| ⭐⭐ | `GameController.cs` | 修改 | ReadInputs() 加网络模式分支 |
| ⭐ | `NetworkConfig.cs` | 配置 | IP/端口/玩家ID |

### 不变文件

| 文件 | 改动 | 原因 |
|------|:--:|------|
| FrameEngine.cs | ❌ | OnRequestInput 委托，网络输入直接注入 |
| FrameBuffer.cs | ❌ | 不关心 Input 来源 |
| FixedInt.cs | ❌ | 确定性计算不变 |
| FrameInput.cs | ❌ | 4 字节结构天然适合网络传输 |

### 学时预估：1.5 ~ 2 小时
