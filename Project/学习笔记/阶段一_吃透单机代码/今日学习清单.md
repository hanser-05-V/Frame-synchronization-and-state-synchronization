## 🔑 FixedInt.cs 拆解（78行，5个部分）

### 第 1 部分：存储格式（3 行）

```csharp
public const int SCALE = 1000;  // 倍率：1.0 = 1000
public int _raw;                 // 底层存储，实际值 = _raw / 1000
```

```
换算:
  _raw = 3500  → 实际值 3.5
  _raw = 100   → 实际值 0.1
```

### 第 2 部分：常量（3 个）

```csharp
Zero = new FixedInt(0)         // _raw=0
One  = new FixedInt(1000)      // _raw=1000, 实际值=1.0
Half = new FixedInt(500)       // _raw=500,  实际值=0.5
```

### 第 3 部分：构造与转换（4 个方法）

```csharp
FromFloat(3.5f) → 3.5×1000=3500 → new FixedInt(3500)  // float → 定点
FromInt(5)     → 5×1000=5000   → new FixedInt(5000)    // int → 定点
ToFloat()      → _raw / 1000.0f                        // 定点 → float（给渲染层）
ToInt()        → _raw / 1000                           // 定点 → int（截断小数）
```

```
调用链:
  float → FromFloat → FixedInt → 逻辑计算 → ToFloat → Transform → 画面
```

### 第 4 部分：四则运算符（核心！）

```csharp
a + b  → new FixedInt(a._raw + b._raw)
         // 3.5 + 2.0 = (3500+2000) = 5500 → 5.5

a - b  → new FixedInt(a._raw - b._raw)
         // 同上，直减

a * b  → new FixedInt((a._raw * b._raw) / SCALE)
         // 3.5 × 2.0 = (3500×2000)/1000 = 7000 → 7.0
         // ⚠ 为什么/1000？两个定点相乘会把倍率放大到 1,000,000 倍
         //    必须 /1000 恢复到只放大 1000 倍

a / b  → new FixedInt((a._raw * SCALE) / b._raw)
         // 3.5 ÷ 2.0 = (3500×1000)/2000 = 1750 → 1.75
         // ⚠ 为什么×1000？不先放大，整数除法会截断小数：3500/2000=1（小数全丢）
```

### 第 5 部分：比较运算符 + 工具

```csharp
== != > < >= <=   → 全部基于 _raw 的整数比较
Equals()          → C# struct 规范
GetHashCode()     → 用于字典 key
ToString()        → 转成 "3.500" 调试用
```

## 🔑 FrameInput.cs 拆解（64行，5个部分）

### 数据结构

```
_raw = 32 bit 全部信息

┌──────────────┬──────────────┬──────────────┐
│   bit 31-16   │  bit 15-8    │   bit 7-0    │
│   保留(不用)  │   moveDir    │   buttons    │
│    16 bit     │    8 bit     │    8 bit     │
└──────────────┴──────────────┴──────────────┘
```

### 第 1 部分：数据存储

```csharp
public uint _raw;  // 全部数据在这一个 uint 里，没有其他变量
```

### 第 2 部分：moveDir — 移动方向（bit 15-8）

```csharp
// 读：右移 8 位，把 bit15-8 移到 bit7-0，取低 8 位
get { return (byte)((_raw >> 8) & 0xFF); }

// 写：清空 bit15-8 → 新值左移 8 位 → 合并
set { _raw = (_raw & 0xFFFF00FF) | (uint)((value & 0xFF) << 8); }
```

方向值：0=停止, 1=↑, 2=↗, 3=→, 4=↘, 5=↓, 6=↙, 7=←, 8=↖

### 第 3 部分：buttons — 按键（bit 7-0）

```csharp
// 读：直接取低 8 位
get { return (byte)(_raw & 0xFF); }

// 写：清空低 8 位，填入新值
set { _raw = (_raw & 0xFFFFFF00) | value; }
```

每个 bit 代表一个按键：bit0=Q, bit1=E（P1）；bit0=Keypad1, bit1=Keypad2（P2）

### 第 4 部分：构造函数

```csharp
// 方式1：给定方向和按键
new FrameInput(moveDir=4, buttons=0)  → _raw=0x00040000

// 方式2：从已有 uint 恢复（回放用）
new FrameInput(0x00040000)  → moveDir=4, buttons=0
FrameInput.FromRaw(0x00040000)  → 同上
```

### 第 5 部分：工具方法

```csharp
Compare(other)  → _raw == other._raw  // 比较
Reset()         → _raw = 0            // 归零
ToString()      → 调试打印
```

## 📊 FrameInput vs FixedInt 对比

| | FrameInput | FixedInt |
|------|------|------|
| **角色** | 信使 | 计算器 |
| 存什么 | 玩家操作（方向+按键） | 游戏数据（坐标/速度） |
| 底层类型 | `uint` | `int` |
| 操作方式 | 位运算（拆字段） | 算术运算（加减乘除） |
| 值域 | 方向0-8，按键0-127 | 坐标可能几万 |
| 联机带宽 | 压缩到 4 字节传给服务器 | 不传——每台机器自己算 |
| 设计目的 | 减少网络传输量 | 保证不同机器计算结果一致 |
| 传递范围 | 跨文件传递（GameController→FrameEngine→回来） | 局部使用（GameController 内部） |
| 生命周期 | 每帧新建 | 持续存在（坐标变量） |

## 🔗 两个类的传递链

### FrameInput — 跨文件传的"信使"

```
GameController.ReadInputs()          ← ① new FrameInput
    ↓ return FrameInput[]
FrameEngine.ExecuteOneFrame()        ← ② 引擎收到
    ├─→ FrameBuffer.AddFrame(inputs) ← ③ 存入环形缓冲
    └─→ OnFrameUpdate(frameID, inputs) ← ④ 回调传回
            ↓
GameController.OnFrameUpdate()       ← ⑤ 消费
    └─→ inputs[i].moveDir  ← ⑥ 读方向，决定方块移动
```

### FixedInt — 局部用的"计算器"

```
GameController 内部:
  _blockPosX[i]  ← FixedInt 变量，存方块坐标

OnFrameUpdate():
  FixedInt speed = FixedInt.FromFloat(5.0f * 0.033f)  ← ① new
  _blockPosX[i] += speed * FixedInt.FromInt(DirX[dir]) ← ② 计算
  _blockPosX[i].ToFloat()  ← ③ 转 float → Transform
```
